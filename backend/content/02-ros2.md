# ROS 2 Fundamentals

## What is ROS 2?
The Robot Operating System 2 (ROS 2) is the industry standard middleware for robotics. It provides a structured communications layer above the OS (usually Linux) to allow different parts of a robot (Nodes) to talk to each other.

## Core Concepts
- **Nodes**: Individual processes that perform a specific task (e.g., camera_driver, motion_planner).
- **Topics**: Pub/Sub mechanism for streaming data. One node publishes messages, others subscribe. (e.g., `/camera/image_raw`).
- **Services**: Request/Response mechanism. Synchronous communication. (e.g., `reset_simulation`).
- **Actions**: Long running tasks with feedback. (e.g., `navigate_to_pose`).

## DDS (Data Distribution Service)
ROS 2 uses DDS as its underlying transport layer, allowing for real-time, reliable communication, which is critical for safety-critical hardware.
