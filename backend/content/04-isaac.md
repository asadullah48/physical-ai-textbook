# NVIDIA Isaac Platform

## Isaac Sim
Built on Omniverse, it uses USD (Universal Scene Description) for assets. It supports RTX ray-tracing for realistic camera simulation (important for vision-based AI).

## Isaac Lab (formerly Orbit)
A modular framework for robot learning built on top of Isaac Sim. It provides environments for tasks like:
- Quadruped locomotion
- Object manipulation
- Humanoid control

## Isaac ROS
Hardware-accelerated ROS 2 packages implementing VSLAM, AprilTag detection, and more using the GPU (CUDA).
